4 pillars of OOP

Pillar	        One-line meaning	                                    Analogy (a car)
Encapsulation	Keep data private, expose controlled access	            Fuel tank is sealed; you use the pedal and the fuel gauge
Abstraction	    Show only what’s needed, hide the complexity	        You press “start” without knowing how the engine fires
Inheritance	    A child class reuses a parent’s properties and methods	A sports car is a car, with extras
Polymorphism	Same method name, different behavior per class	        “Press the horn” sounds different in each car model




Quick reference:
Pillar	        Key JS tools
Encapsulation	#private fields, getters/setters, TS private
Abstraction	    Public methods that hide private helper steps (TS also has abstract classes)
Inheritance	    extends, super
Polymorphism	Method overriding in child classes

One-line summary: encapsulation protects data, abstraction hides complexity, inheritance reuses parent code, and polymorphism lets each child class give the same method its own behavior.
